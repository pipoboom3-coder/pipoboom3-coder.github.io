Privacy Policy: Pipo & Boom Uploader

Last updated: 21 October 2026

The Pipo & Boom Uploader ("the tool") is used only by the owner of the Pipo & Boom YouTube channel to upload the channel's own videos. It uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

The tool requests the YouTube upload permission (scope youtube.upload) and, only to add each uploaded video to the channel's own playlist, the YouTube account permission (scope youtube), for the owner's own Google account only. It sends video files and their title, description, tags and thumbnail to YouTube. It does not read, collect or store any data about viewers or other users, and it does not access any other account.

How data is stored and shared

The OAuth token is stored only on the owner's own computer and is used only to upload the owner's videos. No Google user data is sold, shared with third parties, used for advertising or used to train AI models. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

Access can be revoked at any time at Google security settings. Revoking access and deleting the local token removes all data the tool holds.
